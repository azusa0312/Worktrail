# Worktrail：使用說明

安裝與移除見 [安裝與解除說明](安裝與解除說明.md)；系統如何運作見 [架構與運作原理](架構與運作原理.md)。

## 日常使用

| 做什麼 | 怎麼做 |
| --- | --- |
| 記錄工作 | 不需操作。每次 Claude 回應結束時自動擷取時間、單號、commit；任務告一段落時 Claude 會依 CLAUDE.md 規則寫入摘要 |
| 手動整理本對話 | 在 Code 分頁輸入 `/worklog` |
| 記錄不在 Claude 上的工作 | UI 今日頁或日誌頁按「新增任務」（會議、手動測試、文件等），週報與績效一併統計；有單號時可按「從 Jira 整理」把當天留言整理成子項（內文開頭寫日期的依該日期分段，沒寫日期的依留言建立時間） |
| 補上沒用 Claude 處理的單 | 自動進行：每天 18:00 同步當天你在 Jira 動過的單（建立、移動狀態、留言、編輯），沒有任務的單自動建立「Jira」任務（預設 0.5 小時，可修改）；同單號已有任務時，活動附加到它的補充說明。今日頁「同步 Jira 活動」可立即同步；設定 → Jira 可調整時間、補抓天數、預設時數。自動建立的任務改過子項或時數後不會再被覆蓋，刪除後也不會再建回來 |
| 調整專案 | 任務面板的「專案」欄可從清單選擇或輸入新名稱；設定 → 專案 可新增專案（只填名稱也可以）與自動對應規則 |
| 合併同專案任務 | 同一天同專案有多個任務時，日期列會出現「合併」按鈕，合併成一張卡片 |
| 複製 Jira 進度 | 任務卡片右上角「複製 Jira 進度」，以純文字複製該單號當天的子項，貼到 Jira 留言 |
| 開啟 UI | 點桌面的 Worktrail 捷徑，或輸入 `/worklog-ui`，或 `node dist/cli.cjs open` |
| 產生小交流重點 | UI 報告 → 小交流，勾選日期後按「產生」 |
| 產生週報 | UI 報告 → 週報按「產生」，或在 Code 分頁輸入 `/worklog-weekly`（可帶 `previous` 或 `2026-11-01~2026-11-07`） |
| 產生績效 | UI 報告 → 績效，或 `/worklog-perf` |
| 填年度考核表 | UI 報告 → 績效，期間選「年」，範本選「年度考核表（STAR）」後按「產生」；預覽會照考核表「I. 工作專案與日常任務」排成三欄表格，滑到儲存格上按右上角的複製圖示，貼到 Excel 對應的儲存格即可。標「（可補充數據）」的地方請補上實際數字 |
| 分享報告 | 報告工具列「複製圖片」，直接貼到 Telegram 等聊天軟體 |
| 補寫漏掉的摘要 | 有待補摘要時，今日頁頂端會出現提示，按「前往補寫」後可逐一或全部補寫；每天 18:00 會自動補漏掃描 |
| 調整時數 | 時數預設由 AI 粗估（摘要時）或系統依對話時間計算，在 UI 任務面板直接修改 |
| 每日工時 | 設定頁「記錄」的「每日工時」（預設 8 小時）：同一天 AI 粗估的時數加總超過時，依比例縮減，任務面板會標示「AI 粗估 Xh，依每日工時調整」；手動填寫的時數不變，設為 0 不限制。升級後按「套用到既有紀錄」調整過去的紀錄 |
| 重新設定名字、Jira 代碼、報告週期與外觀 | 設定 → 一般 →「重新執行引導」，走一次第一次開啟時的引導頁 |
| 調整寫法 | UI 的提示詞頁編輯範本，不需改程式（內建範本直接修改會自動另存成你的版本並設為預設）；「試跑」一鍵產生預覽 |

鍵盤：`Ctrl+K` 指令面板、`J`／`K` 在清單中移動、`Enter` 開啟、`Esc` 關閉面板、`Ctrl+S` 立即儲存。

## 指令

| 指令 | 用途 |
| --- | --- |
| `worktrail install` / `uninstall [--purge]` | 安裝／移除 |
| `worktrail doctor` | 檢查安裝狀態並列出修復建議 |
| `worktrail open` / `stop` | 開啟 Worktrail（服務未執行或是舊版時自動啟動）／停止服務 |
| `worktrail sweep` | 立即補漏掃描 |
| `worktrail jira-sync [--date YYYY-MM-DD]` | 立即同步某一天的 Jira 活動（預設今天） |
| `worktrail jira-sync --failed [--date YYYY-MM-DD]` | 列出 Jira 活動同步讀取失敗的單號（不執行同步） |
| `worktrail jira-sync --retry-failed --date YYYY-MM-DD` | 只重新讀取該日期先前失敗的單號 |
| `worktrail analyze <紀錄檔或資料夾> [--table]` | 分析紀錄檔，不寫入任何檔案（驗證用） |
| `worktrail start`、`hook <event>`、`mcp` | 內部使用（啟動器、Claude Code 呼叫），不列在 `--help` 中 |

（未全域安裝時以 `node dist/cli.cjs` 代替 `worktrail`。）

## 資料夾結構

```
<儲存資料夾>/
├─ config.yaml            設定（UI 設定頁可修改）
├─ tasks/2026/11/         每日任務：日期__單號__session前6碼.md
├─ weekly/2026-W46.md     週報
├─ performance/2026-Q4.md 績效
├─ talk/                  小交流重點
├─ prompts/<類型>/*.md    提示詞範本
└─ .worktrail/            系統狀態、單號資訊快取、執行紀錄（logs 保留 14 天）、資源回收區
```

## 隱私

- 所有資料只存在本機；除了呼叫你自己的 `claude -p`，程式沒有任何網路連線（筆記本風格的標題字型會從 Google Fonts 載入，離線時退回系統字型）。
- Jira 資料一律透過你已連線的 Jira MCP 以唯讀工具讀取，Worktrail 本身不呼叫 Jira API。
- 常駐服務只監聽 `127.0.0.1`，檢查 Host 標頭，並以每次啟動產生的 token 驗證。
- 補寫摘要時只送出使用者訊息、Claude 的文字回應、工具名稱與檔案路徑，省略工具輸出。
- 子項與摘要中疑似密碼、金鑰、私鑰的內容會被遮蔽並提示。
